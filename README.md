# Gilanis Distributor's - Wholesale E-Commerce Website

A modern, responsive wholesale distribution website for Gilanis Distributor's, built with HTML5, Tailwind CSS, and Alpine.js.

## Features

- 🏠 **Home Page** - Hero banner, category grid, featured products
- 🛒 **Shop Page** - Product catalog with filters and sorting
- 📦 **Product Detail Page** - Detailed product information with bulk pricing tiers
- 🧮 **Pricing Calculator** - Interactive wholesale price calculator
- 🛍️ **Shopping Cart** - Full cart functionality
- 📱 **Fully Responsive** - Mobile, tablet, and desktop optimized
- 🌓 **Dark Mode** - Toggle between light and dark themes
- 💬 **WhatsApp Integration** - Direct ordering via WhatsApp
